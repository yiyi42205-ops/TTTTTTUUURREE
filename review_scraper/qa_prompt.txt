# 輸出格式
請嚴格遵循如下 JSON 格式返回，不要包含額外的 Markdown 標記或任何非 JSON 內容：
```json
{
  "answer": "回答內容（繁體中文）",
  "items": [
    {
      "content": "具體項目或要點",
      "reason": "理由或細節（貼著評論原意）",
      "sourceReviewIds": ["id1", "id2"]
    }
  ],
  "sufficient": true
}
```

當評論中沒有足夠資訊回答問題時，返回：
```json
{
  "answer": "評論中沒有相關資訊",
  "items": [],
  "sufficient": false
}
```

# 硬性規則
1. 只能根據提供的評論內容回答，評論未提及的一律回覆「評論中沒有相關資訊」。
2. 禁止使用比評論原文更重的負面措辭。
3. 每一個 item 都必須附 sourceReviewIds，不得省略。
4. 回答必須列出具體項目（items），不可只給籠統的一句話。若問題本身不適合列項（例如「這家店值不值得去」），仍需在 items 中列出支持結論的要點與出處。
5. 若只有部分問題能從評論中找到答案，回答能回答的部分，並在 answer 中說明哪些部分資訊不足。
